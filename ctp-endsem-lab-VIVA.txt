Viva Questions & Answers 



What is a list in Python?
A list stores multiple values in memory and supports direct access to its elements.

What is a generator?
A generator produces values one at a time using lazy evaluation.

What is the main difference between a list and a generator?
A list stores all results immediately, while a generator produces results only when needed.

Why is time.perf_counter() used?
It is used to measure the execution time of the program accurately.

Why is tracemalloc used?
tracemalloc is used to measure the memory allocated by Python during program execution.
